# Міні-ігри (Minigames)

Класи, що реалізують окремі ігрові механіки (головоломки).

## HackingGame.java
**Тип:** Міні-гра "Злам".
**Опис:** Гра, де потрібно підібрати правильну послідовність кольорів/символів. Використовується для відкриття захищених дверей або комп'ютерів.
**Функціонал:**
- Генерація випадкового пазла.
- Обробка вводу гравця.
- Відображення ігрового поля (сітка 6x5).

## SentryBotGame.java
**Тип:** Міні-гра "Управління Ботом".
**Опис:** Інтерфейс для керування роботом-вартовим. Дозволяє гравцю бачити очима бота та віддавати команди.

## VendingMachine.java
**Тип:** Інтерфейс торгового автомата.
**Опис:** Дозволяє купувати предмети за кредити UAC. Також містить механіку злому автомата для зниження цін.
