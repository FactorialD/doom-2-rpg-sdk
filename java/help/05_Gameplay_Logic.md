# Ігрова логіка (Gameplay Logic)

## Combat.java
**Тип:** Менеджер бою.
**Опис:** Обробляє покрокову систему бою.
**Функції:**
- `performAttack`: Розрахунок атаки (гравця або монстра).
- `calcHit`, `calcDamage`: Формули влучання та шкоди.
- `radiusHurtEntities`: Логіка вибухів (BFG, ракети).
- Керування снарядами (`activeMissiles`).

## ScriptThread.java
**Тип:** Інтерпретатор скриптів.
**Опис:** Виконує байт-код скриптів карти. Скрипти керують подіями: відкриття дверей, спавн монстрів, діалоги, кат-сцени.
**Зберігає:**
- `IP` (Instruction Pointer): Поточна позиція у скрипті.
- `scriptStack`: Стек даних скрипта.
- `state`: Стан потоку (виконується, пауза, очікування).

## Sound.java / Sounds.java
**Тип:** Аудіо-менеджер.
**Опис:** Відповідає за відтворення звукових ефектів та музики. Використовує `javax.microedition.media`.
- **Sounds.java**: Константи (ID) звукових файлів.

## Enums.java
**Тип:** Глобальні константи.
**Опис:** Містить перелічення для типів сутностей, прапорів, типів зброї, ID спрайтів тощо. Це "словник" гри.

## IStringConstants.java / Languages.java / Translations.java
**Тип:** Константи локалізації.
**Опис:** Допоміжні файли для системи перекладу.
