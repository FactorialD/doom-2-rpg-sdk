# Основна архітектура (Core System)

У цьому файлі описані класи, що відповідають за життєвий цикл програми, головний цикл, управління пам'яттю та ресурсами.

## App.java
**Тип:** Головний клас (MIDlet).
**Опис:** Точка входу в програму. Керує життєвим циклом J2ME додатка (startApp, pauseApp, destroyApp).
**Зберігає:**
- Глобальні посилання на `Display` та `Canvas`.
- Системний час (`gameTime`, `baseTime`).
- Лічильники пам'яті для діагностики.
- Обробку глобальних помилок (`Error`).

## Canvas.java
**Тип:** `javax.microedition.lcdui.Canvas`.
**Опис:** Відповідає за відображення графіки на екрані та обробку низькорівневого вводу (натискання клавіш, дотики екрану). Містить головний ігровий цикл `run()`, який викликає оновлення логіки та перемальовування.
**Зберігає:**
- Стан гри (`state`: меню, гра, інтро, карта тощо).
- Параметри камери (позиція `viewX`, `viewY`, `viewZ`, кути повороту).
- Буфери подій вводу.
- Змінні для керування ефектами екрану (тряска, спалахи).
- Логіку завантаження рівнів (`loadMap`).

## Game.java
**Тип:** Статичний менеджер ігрової логіки.
**Опис:** Центральний хаб ігрової логіки. Керує списком сутностей, монстрів, скриптами та фізикою (зіткненнями).
**Зберігає:**
- `entities`: Масив всіх об'єктів на поточному рівні.
- `mapFlags`: Дані про прохідність та властивості тайлів карти.
- `scriptThreads`: Віртуальна машина для виконання скриптів карти.
- `trace`: Методи для перевірки видимості та зіткнень (Raycasting).
- Методи збереження та завантаження гри (`saveState`, `loadState`).

## Resource.java
**Тип:** Менеджер вводу/виводу (IO).
**Опис:** Забезпечує читання бінарних даних з JAR-архіву та роботу з Record Management System (RMS) для збереження прогресу. Вміє читати стиснуті дані, масиви чисел та специфічні формати гри.
**Зберігає:**
- Буфер вводу/виводу `ioBuffer`.
- Методи доступу до таблиць даних (`loadIntTable`, `loadByteTable`).
- Обробку помилок файлової системи.

## PlatformVars.java
**Тип:** Конфігурація.
**Опис:** Містить константи, специфічні для платформи (коди клавіш, налаштування екрану). Використовується для портування на різні телефони.
