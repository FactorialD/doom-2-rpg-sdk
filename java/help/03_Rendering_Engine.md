# Графічний рушій (Rendering Engine)

Doom 2 RPG використовує власний програмний растеризатор, схожий на спрощений OpenGL, адаптований під J2ME.

## Render.java
**Тип:** Високорівневий рендерер сцени.
**Опис:** Відповідає за підготовку сцени Doom (BSP-дерево, стіни, спрайти) для відмальовки.
**Зберігає:**
- Дані карти: `nodes`, `leafs`, `lines` (геометрія рівня).
- `mapSprites`: Масив спрайтів на карті.
- `textures`, `palettes`: Дані текстур.
- `render()`: Головний метод малювання кадру (небо, стіни, спрайти).
- Логіку обробки "SkyBox".

## TinyGL.java
**Тип:** Низькорівневий растеризатор.
**Опис:** Реалізує математику 3D-проекції, відсікання (clipping) та растеризацію трикутників/квадів.
**Зберігає:**
- Матриці трансформації (`view`, `projection`).
- `pixels`: Головний масив пікселів екрану (Framebuffer).
- `viewport`: Налаштування області виводу.
- Методи `drawModelVerts`, `projectVerts`.

## Span.java, SpanTexture.java, SpanTransparent.java
**Тип:** Растеризатори скан-ліній (Scanline rasterizers).
**Опис:** Відповідають за зафарбовування горизонтальних ліній полігонів.
- **Span**: Базовий клас.
- **SpanTexture**: Малює текстуровані лінії (з корекцією перспективи або афінно).
- **SpanTransparent**: Малює напівпрозорі лінії або лінії з адитивним змішуванням (для ефектів вогню, плазми).

## TGLVert.java / TGLEdge.java
**Тип:** Структури даних.
**Опис:**
- `TGLVert`: Вершина з координатами (x, y, z), текстурними координатами (u, v) та інтенсивністю світла.
- `TGLEdge`: Описує край полігону для алгоритму растеризації.

## Graphics.java
**Тип:** Обгортка над `javax.microedition.lcdui.Graphics`.
**Опис:** Надає зручні методи для малювання 2D-інтерфейсу, тексту та зображень з урахуванням прозорості та поворотів.

## GameSprite.java
**Тип:** Візуальний ефект.
**Опис:** Тимчасовий спрайт, не прив'язаний жорстко до сітки карти (вибухи, снаряди, частинки).

## LerpSprite.java
**Тип:** Анімований об'єкт карти.
**Опис:** Допоміжний клас для плавної інтерполяції (руху) об'єктів, наприклад, дверей, що відкриваються, або монстрів, що йдуть.

## ParticleSystem.java
**Тип:** Система частинок.
**Опис:** Керує масивом дрібних об'єктів (кров, іскри, уламки).
**Зберігає:**
- Масиви координат і швидкостей частинок.
- Методи оновлення та малювання частинок.

## MayaCamera.java
**Тип:** Кінематографічна камера.
**Опис:** Керує рухом камери під час кат-сцен (intro, сюжетні вставки). Зчитує ключові кадри анімації, експортовані з Maya.
