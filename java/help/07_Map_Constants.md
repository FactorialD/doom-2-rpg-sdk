# Константи карт (Map Constants)

- **m_01.java**: Рівень 1 (Вступ, Лабораторія).
- **m_02.java**: Рівень 2.
- **m_03.java**: Рівень 3.
- **m_04.java**: Рівень 4.
- **m_05.java**: Рівень 5.
- **m_06.java**: Рівень 6.
- **m_07.java**: Рівень 7.
- **m_08.java**: Рівень 8.
- **m_09.java**: Рівень 9.
- **m_test.java**: Тестовий рівень (для розробки).
- **MapEnums.java**: Загальні константи для структури файлів карт.
