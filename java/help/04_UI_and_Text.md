# Інтерфейс та Текст (UI & Text)

Класи, що відповідають за HUD, меню та локалізацію.

## Hud.java
**Тип:** Heads-Up Display (Інтерфейс у грі).
**Опис:** Малює елементи інтерфейсу поверх 3D-сцени: здоров'я, патрони, повідомлення, приціл, портрет героя.
**Зберігає:**
- `messages`: Черга текстових повідомлень.
- Зображення елементів інтерфейсу (іконки, рамки).
- Логіку малювання "почервоніння" екрану при болі.

## MenuSystem.java
**Тип:** Менеджер меню.
**Опис:** Керує всіма меню гри (головне меню, інвентар, налаштування).
**Зберігає:**
- `items`: Список поточних елементів меню.
- `menuStack`: Історія переходів по меню.
- Логіку обробки натискань для навігації.

## MenuItem.java
**Тип:** Елемент меню.
**Опис:** Структура даних, що описує один рядок у меню (текст, дію при натисканні, параметри).

## Menus.java / MenuStrings.java
**Тип:** Константи.
**Опис:** Містять ідентифікатори меню та відповідні їм текстові рядки. Визначають структуру меню.

## Text.java
**Тип:** Текстовий рушій.
**Опис:** Заміна стандартного `String` для економії пам'яті. Працює з масивами байтів.
**Зберігає:**
- Шрифти (у вигляді зображень).
- Методи для форматування тексту (перенесення слів, підстановка аргументів `%1`, `%2`).
- Локалізовані рядки, завантажені з файлів.

## SDK... (SDKMoreGames, SDKString, SDKTextUtils)
**Тип:** Бібліотеки EA (Electronic Arts).
**Опис:** Стандартні класи EA для реалізації меню "More Games" (реклама інших ігор) та роботи з текстом у цьому меню.

## Константи рядків (Strings files)
- **Strings.java, FileStrings.java, CodeStrings.java, EntityStrings.java**: Містять ID рядків для локалізації. Використовуються для звернення до текстових ресурсів замість хардкоду тексту.
