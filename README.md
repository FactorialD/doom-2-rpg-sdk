
# Doom II RPG: Modding Suite (Web)

Це комплексний веб-інструмент для модифікації, перекладу та повного реверс-інжинірингу культової мобільної гри **Doom II RPG** (J2ME).

Проєкт працює прямо у браузері, емулюючи файлову систему гри. Він дозволяє завантажити оригінальний `.jar` файл, змінювати ресурси, рівні та логіку скриптів, а потім зібрати робочий мод.

## 🚀 Основні Можливості

### 🌍 3D Редактор Рівнів (Map Editor)
Повноцінний 3D-редактор на базі **Three.js**, що точно відтворює візуальний стиль рушія гри.
- **Рендеринг**: Підтримка геометрії (стіни, підлога, стеля), спрайтів, скайбоксів та напівпрозорих текстур.
- **Режими редагування**:
  - **Select & Inspect**: Вибір об'єктів та полігонів для перегляду властивостей.
  - **Paint**: Швидка зміна текстур на стінах та підлозі (використовує обрану текстуру як "пензлик").
- **Script Link**: Навігація по скриптам. Можливість перейти до скрипта діалогу/події, прив'язаного до тайла на карті.
- **BSP Tree**: Візуалізація дерева розбиття простору (Nodes/Leaves) для аналізу геометрії.
- **Entity Inspector (Read-Only)**:
  - Перегляд координат, типів та прапорів сутностей.
  - Редагування сутностей (переміщення, видалення) **відключено** для забезпечення стабільності скриптів.

### 📜 Студія Скриптів (Script Studio)
Потужне середовище для зміни ігрової логіки (події, діалоги, тригери).
- **Дизасемблер**: Перетворює байт-код гри у читабельний формат.
- **Smart Compiler & Assembler**:
  - Дозволяє **вставляти**, редагувати та видаляти інструкції.
  - **Smart Relocation**: Автоматично перераховує адреси переходів (Jump), викликів функцій та посилань на події тайлів при зміні розміру коду.
- **Intelligent Editor**: Автодоповнення опкодів, підсвітка синтаксису.
- **Visual Editors**: Спеціалізовані GUI-редактори для складних аргументів (наприклад, бітові прапори монстрів `EV_MONSTERFLAGOP` або стилі діалогів `EV_DIALOG`).
- **Structure View**: Бокова панель зі списком функцій та подій карти для швидкої навігації.

### 🎨 Текстурна Студія (Texture Studio)
- **Pixel-Perfect Editor**: Інструменти малювання (Олівець, Пензлик, Заливка) з підтримкою зуму.
- **Smart Import**: Завантаження PNG/JPG файлів. Система автоматично конвертує кольори зображення у найближчі відповідники з активної палітри (Color Quantization).
- **Composite Viewer**: Унікальний режим перегляду складених спрайтів (монстри та NPC у грі збираються з окремих частин: ніг, тулуба, голови). Дозволяє побачити, як монстр виглядатиме у грі.
- **Palette Editor**: Повноцінний редактор 16-колірних палітр. Можливість створення нових палітр та імпорту кольорів із зображень.

### 📝 Локалізація (Text Editor)
- Редагування всіх текстових ресурсів гри (діалоги, назви предметів, інтерфейс).
- Підтримка різних кодувань (Windows-1251, Windows-1252, UTF-8).
- Перегляд атласів шрифтів.

### 🎒 Бази Даних та Аналіз
- **Items Database**: Каталог усіх предметів, зброї та амуніції. Дозволяє знайти, де предмет розташований на карті або використовується у скриптах.
- **Variables Inspector**: Довідник глобальних змінних гри. Показує всі місця у скриптах, де змінна читається або записується (Cross-reference).

## 🎮 Керування у 3D

Редактор підтримує два режими камери:

| Дія | Orbit Mode (Огляд) | Fly Mode (Політ / FPS) |
|---|---|---|
| **Обертання** | ЛКМ + Drag | ПКМ (Затиснути) + Drag |
| **Панорамування** | ПКМ + Drag | - |
| **Переміщення** | - | W, A, S, D |
| **Висота** | - | Q (вниз), E (вгору) |
| **Зум / Швидкість** | Колесо миші | Shift (прискорення) |
| **Вибір / Дія** | ЛКМ (Клік) | - |

> Перемикання режиму польоту кнопкою **Fly** у верхній панелі карти.

## 📦 Як створити мод?

1. **Load JAR**: Натисніть кнопку у верхньому меню та оберіть оригінальний файл `doom2rpg.jar`.
2. **Make Changes**:
   - Змініть текстури стін у вкладці *Textures*.
   - Відредагуйте скрипти рівня у *Scripts* (натисніть *Apply Changes* для компіляції).
   - Модифікуйте текстури карт у *Map* (натисніть *Save Map*).
3. **Save**: Натискайте кнопки збереження у кожному редакторі. Зміни зберігаються у віртуальну файлову систему в пам'яті браузера.
4. **Download**: Натисніть **Download Modded JAR**. Браузер запакує новий файл, готовий до запуску на емуляторі (J2ME Loader) або реальному телефоні.

## 🛠 Технічний стек

- **Angular 21+**: Сучасна архітектура (Zoneless, Signals). Використовує Shared UI компоненти для єдиного стилю.
- **Three.js**: Візуалізація рівнів та BSP-дерев.
- **Tailwind CSS**: Стилізація інтерфейсу.
- **JSZip**: Робота з архівами гри.
- **Binary I/O**: Власна реалізація `BinaryWriter` та `ByteStream` для точної роботи з бінарними форматами гри (Little Endian).
